# Contributing to parser_vet

Thank you for your interest in contributing to parser_vet! We welcome contributions from everyone. Please read this document to understand how to contribute effectively.

## How to Contribute

### 1. Fork the Repository
- Click the "Fork" button on the top right of this repository's page on GitHub.
- Clone your forked repository to your local machine.

### 2. Create a Branch
- Create a new branch for your feature or bug fix:
  ```bash
  git checkout -b feature/your-feature-name
  ```

### 3. Make Changes
- Implement your changes in the code.
- Follow the existing code style and add comments where necessary.
- Ensure your code is well-documented.

### 4. Test Your Changes
- Run the script to ensure it works correctly.
- Check that the output JSON file is generated properly.

### 5. Commit Your Changes
- Commit your changes with a descriptive message:
  ```bash
  git commit -m "Add feature: description of your changes"
  ```

### 6. Push to Your Fork
- Push your changes to your forked repository:
  ```bash
  git push origin feature/your-feature-name
  ```

### 7. Create a Pull Request
- Go to the original repository on GitHub.
- Click "New Pull Request".
- Select your branch and describe your changes.
- Submit the pull request.

## Code Style
- Use Python 3.x compatible code.
- Add comments in Russian for clarity.
- Follow PEP 8 style guidelines where possible.

## Reporting Issues
- Use the GitHub Issues tab to report bugs or request features.
- Provide as much detail as possible, including steps to reproduce the issue.
